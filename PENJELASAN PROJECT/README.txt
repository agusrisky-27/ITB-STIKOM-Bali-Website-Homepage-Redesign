PENJELASAN DESKRIPSI SINGKAT DESAIN WEB HALAMAN UTAMA ITB STIKOM BALI

A. Penjelasan Redesign Proyek

Proyek ini merupakan redesign website ITB STIKOM Bali yang bertujuan untuk meningkatkan kualitas tampilan visual, konsistensi desain, serta kemudahan akses informasi bagi pengguna. Redesign dilakukan karena tampilan dan struktur informasi sebelumnya belum sepenuhnya terintegrasi dan kurang optimal dalam menyajikan informasi kampus secara terstruktur.

Website hasil redesign difokuskan sebagai situs informasi statis yang menampilkan profil kampus, program studi, berita dan pengumuman, kegiatan kemahasiswaan, serta informasi kontak secara jelas, rapi, dan responsif di berbagai perangkat.

Redesign ini juga menekankan pada:

Konsistensi tampilan antar halaman
Navigasi yang mudah dipahami
Penyajian konten yang informatif dan terstruktur
Pengalaman pengguna (User Experience) yang lebih baik

B. Penjelasan Proyek

Judul Proyek:
REDESIGN HALAMAN UTAMA ITB STIKOM BALI  RESPONSIF
Tujuan Utama:
Menyediakan website kampus yang informatif, mudah dinavigasi, dan responsif untuk menampilkan berita, program studi, profil kampus, serta pengumuman pendaftaran.

Target Pengguna:
Calon mahasiswa
Mahasiswa aktif
Dosen dan staf
Masyarakat umum

Fungsi Utama Website:
Halaman Beranda (Home)
Halaman Profil Kampus
Halaman Akademik (Fakultas dan Program Studi)
Halaman Berita dan Pengumuman
Halaman Kemahasiswaan
Halaman Kontak

Hasil Implementasi:
Semua halaman utama terisi konten terbaru
Struktur folder tertata (HTML, CSS, JavaScript, Image)
Footer distandarisasi
Desain responsif untuk desktop dan mobile
Tampilan halaman dibuat konsisten secara visual


C. Konsep Desain yang Digunakan

Website ITB STIKOM Bali menggunakan konsep desain modern, elegan, dan profesional yang mencerminkan identitas institusi pendidikan berbasis teknologi.

1. Gaya Visual
Desain modern dan bersih (clean design)
Menghindari tampilan yang terlalu ramai
Fokus pada keterbacaan dan kenyamanan pengguna

2. Warna
Biru tua sebagai warna utama untuk kesan profesional dan akademik
Biru terang sebagai warna pendukung
Kuning sebagai aksen pada tombol (Call To Action) agar mudah terlihat

3. Tipografi
Menggunakan font sans-serif (Segoe UI / Tahoma / Verdana)
Mudah dibaca di berbagai ukuran layar
Konsisten di seluruh halaman

4. Layout
Grid responsif
Card-based design untuk berita dan program studi
Header dan footer konsisten di semua halaman

5. Alasan Pemilihan Desain
Desain ini dipilih untuk:
Memudahkan pengguna melakukan scanning informasi
Menjaga identitas dan branding kampus
Memberikan pengalaman pengguna yang nyaman di desktop maupun mobile
